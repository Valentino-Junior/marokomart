General Return Policy

At Marokomart, we strive to ensure your complete satisfaction with every purchase. Our return policy varies by product category to ensure the best possible service:

Electronics
  • ✓ 15-day return window
  • ✓ Original packaging required
  • ✓ Functionality test included
Fashion & Apparel
  • ✓ 30-day return window
  • ✓ Unworn condition
  • ✓ Tags attached
Home & Living
  • ✓ 7-day return window
  • ✓ Assembly inspection
  • ✓ Original condition

Return Process

1. Initiate Return

Log into your Marokomart account and select 'Return Item' from your order history

2. Return Approval

Our team will review your return request within 24 hours

3. Package Return

Pack items securely in original packaging with return label

4. Refund Processing

Refund will be processed within 5-7 business days after inspection

Our Quality Guarantee

Every product from Marokomart is backed by our quality guarantee. If you receive a defective item:

  • ✓ Report within 48 hours of delivery
  • ✓ Provide clear photos of the defect
  • ✓ Free return shipping for defective items
  • ✓ Priority processing for quality issues
